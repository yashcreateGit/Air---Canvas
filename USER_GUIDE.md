🎨 How to Use Air Canvas Pro

There are two ways to experience this project: you can try it instantly in your web browser, or download the Python code to run it locally on your computer.

Option 1: Try it Instantly (Web Version)
You do not need to download any files or install Python to test the project. It runs directly in your browser using your device's GPU.
1. Click the live link: [https://yashcreateGit.github.io/Air---Canvas/](https://yashcreateGit.github.io/Air---Canvas/?utm_source=gemini)
2. When prompted, allow the web browser to access your camera.
3. Raise your index finger to start drawing in the air!

Option 2: Run it Locally (Windows & Mac Desktop Version)
If you want to download the source code and run the standalone Python application, follow these steps in your Terminal or Command Prompt:
1. Download the project:
git clone https://github.com/yashcreateGit/Air---Canvas.git
2. Enter the project folder:
cd Air---Canvas
3. Install the required libraries (OpenCV and MediaPipe):
pip install -r requirements.txt
4. Launch the application:
python air_canvas.py
